# Kredence Creative Canvas

Design a very long, vertically-scrolling website wireframe for KREDENCE, a multidisciplinary creative studio (branding, digital, content, video editing, logo design, marketing). Desktop-first, single scrolling page, low-fidelity wireframe with labeled placeholder blocks for images/videos/logos.

COLOR PALETTE (use throughout):
- #64becf (teal — primary accent)
- #363636 (charcoal — text / dark sections)
- #faf9f6 (off-white — background)

TYPOGRAPHY:
- Headings: Prachason Neue Condensed (bold, condensed, large scale)
- Subheadings: Fonetika Mono (monospace, used for labels/tags/small headers)
- Body text: Glacial Indifference (clean sans-serif for paragraph copy)

SECTIONS (top to bottom):

1. NAVIGATION
Sticky nav bar, off-white background. KREDENCE logo left. Menu items in Fonetika Mono: Work, Services, About, Contact. Teal CTA button on the right: "Let's Talk."

2. HERO
Full-width hero, off-white or charcoal background. Bold condensed headline in Prachason Neue Condensed introducing Kredence as a multidisciplinary creative studio. Teal underline/highlight accent on a key word. Short Glacial Indifference sub-line. Teal CTA button.

3. ABOUT / WHO WE ARE
Two-column layout. Left: short bold statement. Right: paragraph in Glacial Indifference on Kredence's approach — strategy, branding, content, digital, marketing working together.

4. SERVICES
Five-card row (or 2x3 grid): Branding & Logo Design, Content & Video Editing, Social Media, Digital & Web Design, Marketing & Campaigns. Each card: icon, Fonetika Mono label, short capability list in Glacial Indifference, teal accent border or icon color.

5. WEBSITES WE'VE BUILT
Grid of 4–6 placeholder website thumbnails shown in browser-frame mockups (address bar + screenshot placeholder), teal frame accents.

6. VIDEOS EDITED
Horizontal scrolling row of placeholder video thumbnails, each with a centered play-button icon overlay.

7. LOGOS DESIGNED
Grid of 6–8 placeholder logo marks, each in a simple square/circle container on off-white background.

8. BRANDS WE'VE WORKED WITH
Grid of exactly 9 dummy client logo placeholders, evenly spaced in a 3x3 grid, each in a teal-outlined box.

9. INDUSTRIES WE'VE WORKED ACROSS
Wide tag/pill cloud in Fonetika Mono listing industries: Automotive, Luxury & Retail, Beauty, Real Estate, Furniture & Interiors, Food & Hospitality, Fragrance & Lifestyle, Media, Personal Brands, Fashion, Technology, Hospitality, Wellness, Education. Pills alternate teal outline / teal fill.

10. PROCESS
Horizontal numbered timeline, 6 steps: Discover → Define → Strategise → Create → Activate → Optimise. Each with a one-line Glacial Indifference description beneath.

11. TESTIMONIALS
2–3 placeholder quote cards side by side, off-white cards with subtle border, client name + title placeholder beneath each quote.

12. FINAL CTA
Full-width charcoal or teal band. Bold condensed headline: "WHAT ARE YOU BUILDING?" Short supporting line. White/off-white CTA button. Contact details row: kredence.co@gmail.com / +91 8879513666.

13. FOOTER
Off-white background. Logo + tagline left. Link columns: Work, Services, About, Contact. Contact info: kredence.co@gmail.com / +91 8879513666. Copyright line in Fonetika Mono, small size.

Maintain consistent grid, spacing, and the teal/charcoal/off-white palette across every section. Keep it a genuinely long page — this should feel like a full, content-rich studio website, not a short landing page.Build a highly interactive, visually rich website for KREDENCE, a multidisciplinary creative studio (branding, digital, content, video editing, logo design, marketing). This should feel alive and tactile — a digital scrapbook/collage aesthetic with real hover interactions and micro-animations throughout, NOT static rectangular blocks or plain cards.

BRAND SYSTEM:
- Colors: #64becf (teal accent), #363636 (charcoal), #faf9f6 (off-white base)
- Fonts: Prachason Neue Condensed (headings, bold/large), Fonetika Mono (labels, tags, small caps text), Glacial Indifference (body copy)

AESTHETIC DIRECTION (maximalist collage / scrapbook):
- Layered, rotated elements — polaroid-style images with visible "tape" corners, sticky-note shaped tags, torn-paper or sticker edges
- Scattered doodle accents: hand-drawn arrows, stars, underlines, small icons placed asymmetrically around text
- Mixed depth — some elements flat, some with subtle drop shadows or a soft 3D/toy-like rendering (like a stylized object or mascot) as a hero centerpiece
- Text treatments with layered/duplicate ghost text behind bold headlines for depth
- Not everything aligned to a strict grid — intentional overlap and rotation, but still readable and organized by section

INTERACTIVITY REQUIREMENTS (every section needs at least one hover/interaction moment):
- Nav links: underline draws in on hover, slight color shift to teal
- Hero: cursor-reactive floating elements (icons/photos drift slightly toward or away from cursor); CTA button has a playful hover state (icon rotates, background fills)
- Service cards: on hover, card lifts and rotates slightly to "straighten," revealing a longer capability list or icon animation
- Portfolio (websites/videos/logos): hover reveals a short preview animation, project name slides in, or a "view project" tag peels in like a sticker
- Brand logos grid (9 client logos): logos are grayscale by default, hover brings them to full color with a slight bounce/scale
- Industries tag cloud: pills wiggle or scale slightly on hover, cursor-follow tilt effect
- Process timeline: numbers animate/count in as user scrolls; hovering a step expands its description
- Testimonials: cards flip or shuffle like a physical stack on hover/click
- Scroll-triggered reveals: elements fade/slide/rotate into place as the user scrolls down (not just a static long page)

SECTIONS:
1. Navigation — sticky, off-white, playful hover underlines, teal CTA button "Let's Talk"
2. Hero — bold layered headline with ghost-text depth effect, scattered doodle icons, cursor-reactive floating photo/icon elements, CTA button
3. About — collage-style layout: taped photos + handwritten-style annotations + core statement, NOT a plain two-column block
4. Services (Branding, Content & Video, Social, Digital, Marketing) — shown as an interactive infographic cluster (e.g. connected nodes or overlapping cards) rather than a grid of identical boxes; hovering each reveals detail
5. Websites We've Built — interactive gallery, hover to preview/animate each site mockup
6. Videos Edited — hover-to-play preview thumbnails with animated play icon
7. Logos Designed — scattered/collaged logo marks, hover brings each into focus
8. Brands We've Worked With — 9 dummy client logos in a playful scattered/tilted arrangement (not a rigid 3x3 grid), grayscale-to-color hover
9. Industries We've Worked Across — animated tag cloud/orbit rather than a static pill list, tags respond to cursor movement
10. Process — interactive numbered timeline, expands on hover/scroll
11. Testimonials — stacked card interaction (click/hover to cycle)
12. Final CTA — full-width teal or charcoal band, bold layered headline, contact details (kredence.co@gmail.com, +91 8879513666) shown as sticker-style tags
13. Footer — grounded, calmer than the rest, logo + links + contact + copyright

Build this as a real responsive site (not a mockup image) with smooth CSS/JS-driven transitions — prioritize personality and tactile interactivity over minimalism, while keeping performance and readability solid.
